# Hohmann Transfer Simulation (NASA GMAT)

Simulation of an orbit-raising maneuver for a sun-synchronous LEO satellite in NASA GMAT, using a differential corrector to target both burns. Results were validated analytically in Python.

- `hohmann_450_500.script` — GMAT mission script
- `validar_hohmann.py` — analytical validation
- `hohmann_reporte.txt` — GMAT results
- `gmat_resultados.png` — altitude plot, 3D view and solver convergence
